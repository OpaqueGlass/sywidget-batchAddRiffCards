## 模式自定义教程

batchAddRiffCards挂件的代码使用Javascript，并未进行压缩、混淆，您可以直接修改源码，和挂件模式相关的代码在`src/modes.js`。

请注意，在挂件版本更新前，您应该自行备份自定义的模式。

### 模式类基本结构和成员说明

- 静态变量id
  用于唯一的区分模式；
- 变量id：
  用于实例化后区分模式，和静态变量id值相同；
- `init()`方法：
  切换模式后自动调用，在这里可以完成模式所需要的基本初始化工作，例如：在挂件界面上创建一个按钮或下拉框；
- `destory()`方法：
  用户切换到其他模式前调用，在这里可以完成移除模式时所需要的操作，例如移除EventListener；
- `load()`方法：
  模式初始化后调用，在这里可以完成模式内部的设置载入，方法参数为：
  - `modeSettings`：通过`save()`方法保存的模式内部设置；
- `save()`方法：
  用户点击保存设置按钮后调用。在这里返回模式需要保存的设置项，设置项应当为一个对象Object；
  
  返回的对象将转换为JSON统一保存在挂件属性中；
- `scan()`方法：
  用户点击检查按钮后调用。在这里根据用户的选择执行检索，返回需要制卡的id数组和目标卡包；

### 约定

> 此传入参数约定用于v0.0.0版，未固定，随时更改。

#### scan()方法

##### 传入参数

挂件将传入一个对象，该对象包括挂件所处环境信息和用户选择信息，如下。

```js
let scanAttr = {
    userSelectDeckInfo: null,/*用户选择的卡包基本信息*/
    userSelectDeckId: g_widget_attr.target_deck_id,/*用户选择的卡包id*/
    allDeckInfo: g_deck_list_temp,/*检索到的所有卡包基本信息数组*/
    currentDocId: "20230201214304-2dlnnbb",/*当前显示在界面上的文档id*/
    openedDocIds: ["20230201214304-2dlnnnn", "20230201214304-2dlnnaa"],/*所有已经被加载为页签的文档id数组*/
};
```

##### 返回值

```js
return [["20230201214304-2dlnnnn"], undefined];
```

- 1.为需要被制卡的块id数组；
- 2.为目标卡包id，块将被加入到对应的卡包中；

  此返回值用于模式需要自行决定卡包的情况；
  **如果在模式中不另外指定目标卡包，请返回`undefined`**；
